# Changelog

## 1.0.0 – 2026-10-23

First release.

- Search as you type over the whole notebook, using Zim's own search engine (Zim 0.77+)
- Text snippets with highlighted search terms for every page found
- Click / arrow keys show the page with the terms highlighted, double click / Enter opens it
- Options: match case, whole word, limit search to the current page and sub-pages
- Adjustable window opacity, optionally fully opaque while the mouse is over the window
- Remembers the last search and the options per notebook
- English and German user interface, following the language of Zim
- Clear "Zim 0.77 or newer" message in the plugin list on older Zim versions
